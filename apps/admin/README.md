# APETIT Admin

Painel operacional da Apetit.

Primeira entrega:
- dashboard;
- unidades e refeitórios;
- importação de cardápio por CSV;
- preview e validação antes da publicação;
- histórico de importações;
- feedback agregado;
- tendências de satisfação.

O painel não deve expor prescrição ou histórico alimentar individual do funcionário.
