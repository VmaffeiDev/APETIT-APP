# APETIT Mobile

Aplicativo do funcionário.

Stack planejada: React Native + Expo + TypeScript.

Primeira entrega de interface:
- autenticação/onboarding;
- Home;
- cardápio do dia;
- controle nutricional;
- sugestão de prato;
- registro da refeição;
- feedback;
- perfil.

As regras nutricionais e de alergênicos não devem ser duplicadas no cliente.
